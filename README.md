# 삼국지 드래프트 — 竹簡

게임은 `index.html`을 편집합니다. HTTP(S)에서는 `/sam/` 또는 `/sam/index.html`로 접속하고, 로컬에서는 이 폴더 전체를 내려받아 `index.html`을 엽니다. ES Module이나 빌드 과정은 사용하지 않습니다.

## 파일 구성

- `index.html`: 화면, 데이터, 게임 규칙. 초상은 상대 경로로 참조합니다.
- `images/portraits/`: 카드·도감용 초상 267개.
- `images/large/`: 확대용 초상 34개. 확대본이 없는 인물은 카드용 이미지를 사용합니다.
- `images/manifest.json`: 원본에서 추출한 파일별 크기와 SHA-256. 최초 분리 시 원본 바이트를 보존했습니다.
- `icons/`: 홈 화면 앱 아이콘.
- `sam.webmanifest`: 앱 설정. 기존 앱의 식별자 `../sam.html`을 유지합니다.
- `tests/`: 게임 회귀 검증과 파일·경로·이동 검증.

새 초상을 교체할 때는 대응하는 이미지 파일을 교체합니다. 새 인물의 초상을 추가할 때는 `IMG` 또는 `IMGL`의 이름→경로 항목도 등록합니다. 이미지 파일을 바꾸면 `images/manifest.json`의 크기와 해시도 함께 갱신합니다.

## 기존 주소와 저장 데이터

저장소 루트의 `sam.html`은 이 게임으로 이동하는 호환 진입점입니다. 검색 문자열과 해시를 유지합니다. HTTP(S) 전적·설정·진행 저장은 같은 origin과 기존 localStorage 키를 사용하므로 경로 이동으로 초기화하지 않습니다.

`file://`에서 기존 `sam.html`로 진입하면 기존 페이지에서 읽을 수 있는 게임 저장값을 새 페이지에 전달합니다. 새 위치에 이미 저장된 값은 덮어쓰지 않으며, 원래 위치의 데이터도 삭제하지 않습니다. 로컬 파일 저장소의 지원 여부는 브라우저에 따라 다릅니다.

수동 백업의 기존 위치인 **저장소 루트 `data-sam/save.json`**은 유지합니다. 게임에서는 `../data-sam/save.json`을 읽습니다. 기존 백업 갱신 방법과 설치된 앱을 위해 루트 manifest·아이콘도 남겨두었습니다. 새 게임의 manifest와 아이콘은 이 폴더에 있습니다.

## 화면

새 대국은 **후보 6장 · 13번 지명 · 최종 11명**입니다. 초기 버전의 화면과 카드·낙관·결의 이펙트를 사용합니다. 후보는 2열×3행으로 표시하며 카드를 누르면 바로 지명합니다. 결의 알림은 화면 중앙에 표시합니다.

처음 11번은 기존 역할 정원을 적용하고, 마지막 2번은 자유 예비 지명입니다. 마지막 화면에서 점수가 높은 11명 편성을 추천하며 직접 교체할 수 있습니다. 역할 규칙을 켰을 때 군주 1·무장 5·참모 5를 우선하며, 기존 후보 부족 예외로 정상 편성이 불가능한 경우 가능한 최소 정원 초과만 허용합니다.

AI도 13명을 지명한 뒤 동일한 추천 계산으로 11명을 확정합니다. 시나리오의 적은 기존 고정 11명입니다. 예비 지명 중 점수·인연은 추천 11명 기준으로 표시하고, 결과·전적에는 확정한 11명만 반영합니다.

최종 편성 도중의 선택도 자동 저장합니다. 이전 버전의 저장 대국은 11회 규칙과 후보 수로 마무리하며, 다음 새 대국부터 13회·6장 규칙을 적용합니다.

## 검증

저장소 루트에서 실행:

```sh
node sam/tests/assets.cjs
node sam/tests/regression.cjs
```

기존 `node sam-regression.test.cjs` 명령도 새 검증 파일을 호출합니다. 회귀 검증은 DOM 대역으로 게임 함수를 실행하며 실제 브라우저 렌더링 검증을 대체하지 않습니다.
