# 삼국지 쟁탈전

https://polos0117.github.io/sam-atelier/ — 게임은 `index.html`을 편집합니다. 로컬에서는 저장소를 내려받아 `index.html`을 엽니다. ES Module이나 빌드 과정은 사용하지 않습니다.

## 파일 구성

- `index.html`: 화면, 데이터, 게임 규칙. 초상은 상대 경로로 참조합니다.
- `lib/speech.js`: 말풍선. 취한 장수가 제 한 줄(`LORE`)을 진영 칸 위에서 합니다(적장은 안개가 아닐 때만).
- `lib/today.js`: 오늘 기록. 다섯 공방이 한 출처(polos0117.github.io)라 localStorage 를 같이 쓰며, 대국이 끝나면 `atelier_today_v1:samguk` 에 `{d, n, w, daily, at, seen}` 한 칸을 적고 공방 지도가 읽어 군막에 불을 켭니다. 모양의 약속은 지도 저장소 README 「오늘 기록」절에 있습니다.
- `images/portraits/`: 카드·도감용 초상 267개.
- `images/large/`: 확대용 초상 34개. 확대본이 없는 인물은 카드용 이미지를 사용합니다.
- `images/manifest.json`: 원본에서 추출한 파일별 크기와 SHA-256. 최초 분리 시 원본 바이트를 보존했습니다.
- `icons/`: 홈 화면 앱 아이콘.
- `sam.webmanifest`: 앱 설정.
- `data-sam/save.json`: 수동 백업. 게임이 읽어 복원합니다.
- `tests/`: 게임 회귀 검증과 파일·경로·이동 검증.

새 초상을 교체할 때는 대응하는 이미지 파일을 교체합니다. 새 인물의 초상을 추가할 때는 `IMG` 또는 `IMGL`의 이름→경로 항목도 등록합니다. 이미지 파일을 바꾸면 `images/manifest.json`의 크기와 해시도 함께 갱신합니다.

## 기존 주소와 저장 데이터

`atelier` 저장소의 `sam/`에서 분리했습니다(이력 보존). 옛 주소 `/atelier/sam.html`·`/atelier/sam/`은 이 저장소로 이동합니다. 같은 origin(`polos0117.github.io`)이라 localStorage 전적·설정·진행 저장은 그대로 이어집니다.

## 화면

**오늘의 대국**(새 대국 설정의 단추, 또는 주소 `?daily`)은 날짜가 씨앗이라 하루 동안 후보 죽간·적장의 수가 같습니다. 승부에 드는 난수만 씨앗을 따르고 대사·대국 번호는 그대로 무작위입니다. 이어하기한 대국은 남은 수를 무작위로 둡니다.

새 대국은 **후보 6장 · 13번 지명 · 최종 11명**입니다. 초기 버전의 화면과 카드·낙관·결의 이펙트를 사용합니다. 후보는 2열×3행으로 표시하며 카드를 누르면 바로 지명합니다. 길게 누르면(PC에서는 오른쪽 클릭) 지명하지 않고 상세를 열어 살펴본 뒤 확정할 수 있습니다. 지명이 오간 대국이 진행 중일 때 새 대국을 시작하면 단추를 한 번 더 눌러 확인합니다. 결의 알림은 화면 중앙에 표시합니다.

처음 11번은 기존 역할 정원을 적용하고, 마지막 2번은 자유 예비 지명입니다. 마지막 화면에서 점수가 높은 11명 편성을 추천하며 직접 교체할 수 있습니다. 역할 규칙을 켰을 때 군주 1·무장 5·참모 5를 우선하며, 기존 후보 부족 예외로 정상 편성이 불가능한 경우 가능한 최소 정원 초과만 허용합니다.

AI도 13명을 지명한 뒤 동일한 추천 계산으로 11명을 확정합니다. 시나리오의 적은 기존 고정 11명입니다. 예비 지명 중 점수·인연은 추천 11명 기준으로 표시하고, 결과·전적에는 확정한 11명만 반영합니다.

11명을 확정하면 **결전 장면**이 결과 위에 한 번 덮입니다 — 전력이 높은 순으로 짝지은 합을 한 합씩 보여 주고(아군 승·근소·무승부·패, 참고 비교), 끝에 승패와 점수. 누르면 건너뛰고, 빠른 진행이나 움직임 줄이기면 장면 없이 바로 결과입니다. 승패 규칙은 그대로입니다.

최종 편성 도중의 선택도 자동 저장합니다. 이전 버전의 저장 대국은 11회 규칙과 후보 수로 마무리하며, 다음 새 대국부터 13회·6장 규칙을 적용합니다.

## 검증

```sh
node tests/assets.cjs
node tests/regression.cjs
node tests/sprite-actor-copy.cjs
```

회귀 검증은 DOM 대역으로 게임 함수를 실행하며 실제 브라우저 렌더링 검증을 대체하지 않습니다.

## 공용 모듈

`lib/` 의 파일은 공방 모음(polos0117.github.io)이 원본인 공용 모듈입니다 — 오늘 기록 `today.js`, 말풍선 `speech.js`, 도트 재생기 `sprite-actor.js`·`sprite-actor.css`(판 v1). 여기서 따로 고치지 않습니다. 고치면 원본과 다섯 저장소를 같이 고치고, `node tests/sprite-actor-copy.cjs` 가 도트 재생기를 원본과 견줍니다(약속은 그쪽 README 「도트 재생기」절, 도트 인물의 그림은 도트 공방 `dot.html` 에서 만듭니다). 아직 이 공방에서 도트 인물을 세우는 화면은 없습니다.
